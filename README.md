# Capacitacao-Interna-LASI
este repositório é reservado para o desenvolvimento de projetos voltados para a capacitação interna dos membros da Liga Acadêmica de Sistemas Inteligentes "LASI"

código: Sistema de Biblioteca Pessoal

Permite o gerenciamento de uma biblioteca de livros 

funcionamento: 

/ exibe o menu com as opções

/ lê a opção do usuário

/ armazena nomes de livros e status em arrays fixos

/ para cadastro verifica duplicados e permite cancelar

/ busca e atualiza livros por nome exato, removendo e rearranjando a lista quando necessário
